# Relationship Engine v1

Human Infrastructure for Modern Life.

A mobile-first PWA for relationship continuity, outreach discipline, peripheral network activation, and communication calibration.

## Features
- Relationship dashboard
- Add/manage people
- Interaction debriefs
- Quick Swings
- Follow-up tracking
- Peripheral Network view
- Recent momentum timeline
- Dark/light mode
- LocalStorage persistence
- JSON export/import
- Offline-first PWA shell

## Deployment
Upload the folder contents to GitHub Pages or any static web host.
